Mission Control — Operator

Writes are recorded under your actor ID. On servers that issue per-actor tokens, the token determines who you act as: the write is recorded under the actor the token was issued to, and an actor ID that disagrees with the token is rejected — the shared operator token can read but cannot write on those servers. Your authority is the role recorded for that actor ID in the store — leave the role blank to act under the recorded role. If you enter a role, the server rejects the write when it does not match the record. The token and session fields stay in this browser tab only.
